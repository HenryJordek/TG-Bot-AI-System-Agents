# AI Telegram Bot

Телеграм-бот с локальным ИИ (Ollama), который общается с пользователями, ищет в интернете и запоминает личные факты.

## Возможности

- Локальная LLM через [Ollama](https://ollama.com) — без облака, без API-ключей, полностью оффлайн
- Поиск в интернете через DDGS, когда ИИ нужны свежие данные
- Долговременная память через ChromaDB (векторная база данных)
- Поддержка прокси и кастомного API (HTTP / SOCKS5 / Cloudflare Workers)

## Команды

- `/start` — приветствие
- `/help` — список доступных команд

Бот также отвечает на любое сообщение, не начинающееся с команды, так что можно просто общаться с ним.

## Как это работает

1. Пользователь отправляет сообщение боту.
2. Бот параллельно делает три вещи:
   - решает, нужен ли поиск в интернете
   - извлекает личные факты из сообщения
   - подтягивает релевантные факты из памяти (ChromaDB)
3. Если найден личный факт — поиск и память пропускаются (пользователь просто говорит о себе).
4. Иначе бот ищет в интернете и добавляет результаты в промпт.
5. ИИ генерирует ответ, используя: системный промпт + текущее время + память + веб-контекст.
6. Ответ отправляется пользователю. Если это был личный факт — он сохраняется в память.

## Установка

### Требования

- Python 3.10 или выше
- Установленная и запущенная [Ollama](https://ollama.com)
- Токен Телеграм-бота (получить у [@BotFather](https://t.me/BotFather))
- Прокси или кастомный API (нужно только в регионах, где Telegram заблокирован)

### 1. Клонировать репозиторий

    git clone https://github.com/HenryJordek/telegram-AI-Agent-bot.git
    cd telegram-AI-Agent-bot

### 2. Установить Python-зависимости

    pip install -r requirements.txt

### 3. Скачать модели Ollama

    ollama pull qwen2.5:3b
    ollama pull nomic-embed-text

`qwen2.5:3b` — это чат-модель (меняется в `.env`).
`nomic-embed-text` — модель эмбеддингов для памяти ChromaDB.

### 4. Настроить окружение

Скопируйте пример и отредактируйте его:

    cp .env.example .env

Заполните `.env`:

    # Telegram Bot Configuration
    TOKEN=your_telegram_bot_token_here
    PROXY=http://127.0.0.1:10808
    API=

    LOG_LEVEL=INFO
    DEBUG=0

    MODEL_NAME=qwen2.5:3b
    CHROMADB_PATH=./chromadb
    EMBED_MODEL=nomic-embed-text
    OLLAMA_URL=http://localhost:11434
    MAIN_DEVICE=gpu
    AI_PROMPT=You are a helpful AI assistant. Reply concisely.

### 5. Получить токен бота

- Откройте Telegram и напишите [@BotFather](https://t.me/BotFather)
- Отправьте `/newbot` и следуйте инструкциям
- Скопируйте полученный токен в `TOKEN=` в `.env`

### 6. Настроить прокси или API (опционально)

Если Telegram заблокирован в вашем регионе, укажите одно из:

    HTTP proxy:    PROXY=http://127.0.0.1:8080
    SOCKS5 proxy:  PROXY=socks5://127.0.0.1:1080
    Custom API:    API=https://your-cloudflare-worker.example.com

Достаточно указать что-то одно — `PROXY` или `API`. Если заданы оба, `PROXY` имеет приоритет.
Если не указано ни то, ни другое — бот подключается к Telegram напрямую (это нормально для регионов без блокировок).

### 7. Запустить бота

    start.bat

Или напрямую:

    python main.py

## Хранение данных

История чата **не** сохраняется. В ChromaDB в виде векторных эмбеддингов сохраняются только личные факты о пользователях (имя, возраст, профессия, предпочтения) — и только для текущего пользователя.

Данные лежат в папке, указанной в `CHROMADB_PATH`.

## Решение проблем

- **"Model not found"** — укажите `MODEL_NAME` в `.env` и выполните `ollama pull <модель>`.
- **Бот не отвечает** — проверьте `PROXY` / `API` в `.env` и что `ollama serve` запущен.
- **Первый ответ долгий** — модель загружается в VRAM. Бот прогревает её при старте, но если пропустить прогрев, первый запрос может занять 30+ секунд.
- **Модель остаётся в VRAM после выхода** — это норма (Ollama держит её 24 часа). Чтобы выгрузить вручную: `ollama stop <модель>`.
